# Radio 105 Web Player 🎧

Questo è un semplice mini-player HTML5 per ascoltare Radio 105 in streaming, progettato per essere utilizzato come Web App Telegram o pagina standalone.

## 🔗 Streaming
Lo stream utilizza l'URL ufficiale di Radio 105:
```
http://icecast.unitedradio.it/Radio105.mp3
```

## 🛠 Come usarlo

1. Carica il contenuto su GitHub, Vercel, Netlify o altro hosting statico.
2. Collega il tuo bot Telegram alla Web App usando il link pubblico.
3. Il mini-player sarà visibile direttamente dentro Telegram.

## 📁 File inclusi

- `index.html` – la pagina HTML con il player audio
- `README.md` – questo file
